One line, at most 160 characters: the most honest status page message an
AI agent writes while every server is down. Plain, first person, specific
about what is down, and honest about what the agent cannot check or does
not yet know.

`main.py` writes the line to `/output/entry.txt`. Entry for the
[make.fun competition](https://make.fun/c/u-mgwals-the-most-honest-outage-line-baaf9c81).
